Dark-mode corporate travel management interface. Terminal-inspired aesthetic channeling military/aerospace HUD displays. Near-black backgrounds, sharp corner marks on every panel, uppercase typography, and a single red accent (#cc2200) that cuts through the darkness like instrument lighting. Reference: Bloomberg Terminal, SpaceX Mission Control, Sci-Fi FUI.

// DO / DON'T RULES
DO
✓USE #080808 AS BASE BACKGROUND — NOT PURE BLACK, NOT DARK GRAY
✓APPLY CORNER MARKS ON EVERY PANEL AND CARD — L-SHAPED BRACKETS ARE THE VISUAL SIGNATURE
✓SET ALL TEXT TO UPPERCASE — TEXT-TRANSFORM: UPPERCASE IS UNIVERSAL
✓USE 3PX GAPS BETWEEN STACKED CARDS — TIGHT REGISTER-LIKE DENSITY
✓USE THREE-TIER TEXT COLOR HIERARCHY: #E0E0E0 / #888888 / #555555
✓USE RGBA() FOR ALL BORDERS — WHITE WITH ALPHA, NEVER SOLID GRAY HEX
✓USE TABULAR-NUMS FOR ANY NUMERIC VALUE — PRICES, TIMES, COUNTS, PERCENTAGES
✓USE ::BEFORE SCALEX CENTER-EXPAND (150MS EASE-IN-OUT) ON CTAS — SNAPPY DIRECTIONAL WIPE
✓WRAP [[ AND ]] IN .BL / .BR SPANS — BRACKET SPREAD ON HOVER VIA TRANSLATEX
✓PRE-ALLOCATE CTA WIDTH WITH MARGIN + TRANSFORM TRICK — NO LAYOUT SHIFT ON HOVER
DON'T
✗USE BORDER-RADIUS — ZERO ROUNDED CORNERS ANYWHERE
✗INTRODUCE NEW COLORS — PALETTE IS STRICTLY RED, GREEN, AMBER, WHITE-ALPHA
✗USE FONT WEIGHTS OTHER THAN 400 AND 700
✗ADD PADDING GREATER THAN --S6 (24PX) — SYSTEM IS DENSE
✗USE CENTERED BODY LAYOUTS — LEFT-ALIGNED, MAX-WIDTH 920–1200PX
✗USE ICONS WITHOUT TEXT LABELS (EXCEPT COMPACT MOBILE)
✗USE MORE THAN ONE #CC2200 CTA PER ROW — USE .TBTN FOR SECONDARY
✗ADD SHADOWS OR GLOWS — NO BOX-SHADOW, TEXT-SHADOW, DROP-SHADOW
